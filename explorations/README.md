# Design explorations

Document ideas and alternatives here without authorizing development. Statuses are
active, selected, parked and rejected. Selected means chosen for integration into
a linked change; an approved handoff requires its own review and release.

| ID | Question | Status | Result |
| --- | --- | --- | --- |
| [EXP-0001](EXP-0001/README.md) | My Bookings tabs or sections? | Active | No option selected; DEC-006 remains open |

Use [the template](../templates/exploration.md), a short-lived branch and an issue.
Update registries/explorations.json. Preserve rejected/parked rationale. Isolate new
experimental source in its directory and label it Exploration. Existing candidate
routes can be linked instead of copied. See [the shared workspace model](../docs/06_Shared_Design_Workspace.md).
