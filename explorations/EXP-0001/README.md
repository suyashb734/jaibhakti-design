# EXP-0001 My Bookings tabs or sections

Status: Active. Human owner: unassigned. Selection: none. Engineering approval: none.

This records an existing unresolved comparison, not a newly designed alternative.
Both options remain in the draft candidate and relate to JB-CHG-0001 and DEC-006.
Baseline source commit: f3aa8833dd591651463a41d2661c07c06b91ba8a.

## Question and options

Can devotees distinguish ongoing Nirantar bookings, upcoming registered dates and
performed dates more reliably with category tabs or sections on one page?

| Option | Existing source | States |
| --- | --- | --- |
| A: category tabs | [Nirantar](../../previews/mobile/Prototype.html#bookings/nirantar), [Upcoming](../../previews/mobile/Prototype.html#bookings/upcoming), [Completed](../../previews/mobile/Prototype.html#bookings/completed) | JB-APP-003, JB-APP-004, JB-APP-005 |
| B: sections | [Combined sections](../../previews/mobile/Prototype.html#sections) | JB-APP-006 |

These links show the working source. The baseline commit identifies the historical
version; frozen reference PNGs remain in the screen registry. No new source copy is
needed merely to document this exploration.

## Comparison criteria and evidence needed

Use identical sample accounts, bookings and media states at the same viewport.
Ask reviewers to find the next registered date, identify an ongoing booking and its
beneficiary, find a performed date's media, and explain a payment problem. Record
task success/attempts, errors, time and qualitative confusion with participant
details. Check keyboard focus, long names, empty lists and multiple beneficiaries.
Agree the evaluation targets before testing. No comparative usability result has
been collected by this record; neither option is claimed superior.
